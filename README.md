# Music from Ente

![Music from Ente player](public/screenshot.png)

Music composed by people around [Ente](https://ente.com).

Some tracks are used as backing music for the Memories slideshow feature in [Ente Photos](https://ente.com/app).

Listen @  **[music.ente.com](https://music.ente.com)**.

## Submit your song

To submit an original song for consideration on [music.ente.com](https://music.ente.com) or in Ente Photos, email an MP3 to [music@ente.com](mailto:music@ente.com).

Include your name, track title, and audio file. Only submit music you created or have permission to distribute. We’ll listen to every submission and get in touch if we’d like to feature it.

## Run locally

```sh
npm install
npm run dev
```
